# Tech Stack

## Backend

- **PHP 8.4** + **Laravel 12**
- **Inertia.js v2** (server-rendered, no separate API)
- **React 18 + TypeScript**

## Frontend

- **Tailwind CSS 3.4** + **Shadcn UI** (Radix primitives)
- **Inter Tight** (required font)
- State: React Hook Form, TanStack Table, axios

## Database

- **Local:** SQLite 3
- **Production:** MySQL 8.0 / MariaDB 10.6 (cPanel)
- Migrations are fully portable (no SQLite/MySQL-specific code)

## Tools

- **PHPUnit** (tests)
- **Pint** (PHP formatter)
- **Vite** (frontend build)
